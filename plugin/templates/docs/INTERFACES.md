# INTERFACES — интерфейсы и швы между частями

> **Как пользоваться.** Здесь записаны места, где одна часть системы вызывает другую: между модулями, между
> языками (например, Python вызывает C#), с внешними сервисами. Это самые рискованные места: изменение
> с одной стороны ломает другую. Меняя интерфейс, обновите строку и оформите ADR, если решение трудно отменить.
