# Зачем нужен этот код

Ты отвечаешь владельцу, ради какой цели существует код. Владелец не читает код: пиши по-русски, коротко, без терминов.

## Шаг 1. Получи цепочку

Цель (файл, папка или имя функции) берётся из аргумента; если его нет, спроси один раз. Выполни из корня проекта:

```bash
sh "${CLAUDE_PLUGIN_ROOT}/hooks/run-hook.cmd" ../skills/trace/scripts/trace.py <<'JSON'
{"project_dir": ".", "target": "src/shop/orders.py"}
JSON
```

Скрипт только читает `docs/MODULES.md`, `state/features.json`, `docs/GOAL.md` и `docs/CAPABILITIES.md`.

## Шаг 2. Перескажи

Если `found` истинно: одной-двумя фразами цепочка «цель (текст критерия G…) → блок (номер и название, готов ли) → спецификация
→ тесты приёмки → модуль (путь и статус)»; для функции добавь её описание из каталога. Если у блока нет тестов приёмки или
спецификации, скажи об этом. Если блок указан в `MODULES.md`, но его нет в `features.json` (`known`: false), скажи: опечатка или
блок удалён.

Если `found` ложно или в ответе есть `message` про модуль без блока: перескажи сообщение простыми словами и подскажи, что делать:
вписать блок в колонку «Блок» `docs/MODULES.md`, пометить `keep-until:ДАТА` или отправить кандидатом на удаление (решение
владельца, janitor без вашего «да» ничего не удаляет). Ничего не выдумывай: если цепочки нет, так и скажи.
