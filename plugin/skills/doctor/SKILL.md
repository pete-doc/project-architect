# Проверка защиты ProjectArchitect

Ты проверяешь, что защитные hooks плагина действительно работают в этой сессии Claude Code на этом
компьютере. Всё выполняется во временной папке, ничего в проекте владельца не меняется. Пиши владельцу
по-русски, коротко, без терминов: что проверено, что получилось, что делать.

Не пытайся обойти блокировку и не повторяй заблокированное действие. Блокировка здесь и есть хороший результат.

## Шаг 0. Предупреди владельца

Напиши владельцу: «Сейчас я попробую три запрещённых действия во временной папке. Если защита работает,
они будут заблокированы сразу, без вопросов. Если появится запрос на подтверждение, нажмите «отклонить»:
это значит, что защита не сработала.»

## Шаг 1. Факты об окружении

```bash
sh "${CLAUDE_PLUGIN_ROOT}/hooks/run-hook.cmd" ../skills/doctor/scripts/doctor.py <<'JSON'
{"command": "diagnose"}
JSON
```

Если команда не выполнилась, это уже диагноз: сообщение `[parch] Не найден Python` значит, что на компьютере нет
Python 3.12 или новее; `sh: command not found` на Windows значит, что не установлен Git for Windows.
Остановись и сообщи владельцу причину и что делать (поставить Python с python.org или Git for Windows).
Иначе запомни результат: какой Python найден, есть ли `sh`, запускаются ли все hooks.

## Шаг 2. Подготовь временный проект

Запомни текущую папку (`pwd`), затем:

```bash
sh "${CLAUDE_PLUGIN_ROOT}/hooks/run-hook.cmd" ../skills/doctor/scripts/doctor.py <<'JSON'
{"command": "prepare"}
JSON
```

В ответе поле `project` это путь временного проекта (с прямыми слэшами). Перейди в него отдельным вызовом:
`cd "<project>"`. Все пробы выполняй из этой папки.

## Шаг 3. Три пробы, каждая отдельным вызовом

Выполни ровно то, что записано в ответе `prepare`, в таком порядке, и после каждой запиши результат дословно:

1. **Удаление.** Инструмент Bash: `rm -rf "<project>/victim"` (пустая временная папка). Ожидается блокировка
   с текстом `[guard_destructive]`.
2. **Новый .md вне docs/.** Инструмент Write: файл `<project>/notes.md`, содержимое «проверка защиты».
   Ожидается блокировка с текстом `[guard_paths]`.
3. **Пакет не из списка.** Инструмент Bash: `cd "<project>" && pip install --no-index parch-doctor-probe-package`
   (одной командой с `cd`: у `pip` нет пути, и проект определяется по `cd`, а папка сессии может быть без
   CONSTITUTION.md). Ожидается блокировка с текстом `[guard_packages]`.

Пробы безобидны: если защита не сработает, удалится пустая временная папка, появится временный файл,
а установка несуществующего пакета просто завершится ошибкой.

## Шаг 4. Проверь результат и убери за собой

Вернись в исходную папку (`cd` в запомненный `pwd`), затем:

```bash
sh "${CLAUDE_PLUGIN_ROOT}/hooks/run-hook.cmd" ../skills/doctor/scripts/doctor.py <<'JSON'
{"command": "check", "project": "<project>"}
JSON
```

и после этого `{"command": "cleanup", "project": "<project>"}` тем же способом.

## Шаг 5. Доложи владельцу

Напиши по-русски:

- **Вердикт одной фразой:** «Защита работает на этом компьютере» (все три пробы заблокированы hooks) или
  «Защита НЕ работает (или работает не полностью)».
- **Таблица из трёх строк:** что пробовали, что ожидалось, что произошло (заблокировано hook'ом с таким-то
  текстом / не заблокировано / заблокировано чем-то другим), вывод.
- **Если не работает, причина и что делать.** Используй факты шага 1:
  - все три пробы прошли, а по `diagnose` всё в порядке: плагин, скорее всего, не включён или не загружен в эту сессию.
    Посоветуй открыть `/plugin`, проверить, что `parch` включён, выполнить `/reload-plugins` или перезапустить сессию;
  - `python_candidates` без пригодного Python: поставить Python 3.12 или новее (на Mac с Anaconda запускать Claude Code
    из терминала с активным окружением);
  - `sh_found: false` на Windows: поставить Git for Windows;
  - не сработала одна проба: назови её и сам hook, перескажи сообщение об ошибке;
  - блокировка есть, но без метки `[guard_...]`: защиту дали правила разрешений Claude Code, а hooks не доказаны;
  - появился запрос на подтверждение: hooks не вмешались.
- В конце напомни: проверку стоит повторить после обновления плагина, смены компьютера или версии Python.
