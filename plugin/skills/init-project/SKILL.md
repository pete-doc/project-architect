# Подключение проекта к ProjectArchitect

Ты помогаешь владельцу подключить проект. Владелец не программист: говори по-русски, коротко, на языке
последствий (что появится, что изменится, как откатить), без терминов реализации.

## Шаг 1. Задай вопросы

Задай владельцу 3–5 вопросов. Если доступен инструмент AskUserQuestion, используй его, иначе спроси в чате.
Не задавай больше пяти вопросов и не спрашивай то, что уже ясно из ответов.

1. **Как называется проект и что он делает?** Одна-две фразы своими словами.
2. **На каких языках он пишется?** Варианты: Python, TypeScript, C#, PowerShell (можно несколько).
3. **Что для вас важнее всего?** Например: надёжность, скорость разработки, низкая стоимость, понятность,
   безопасность данных (можно несколько).
4. **В какой папке создавать проект?** По умолчанию текущая (`$ARGUMENTS`, если передан аргумент).
5. **Код уже есть?** Если да, после подключения предложи `/parch:analyze-existing`, чтобы разобрать его.

## Шаг 2. Выполни подключение

Запусти команду, подставив ответы владельца в JSON. Языки пиши латиницей: `python`, `typescript`,
`csharp`, `powershell`. Команда ничего не перезаписывает: существующие файлы она пропускает.

```bash
sh "${CLAUDE_PLUGIN_ROOT}/hooks/run-hook.cmd" ../skills/init-project/scripts/init_project.py <<'JSON'
{
  "project_dir": ".",
  "name": "НАЗВАНИЕ",
  "languages": ["python"],
  "description": "ЧТО ДЕЛАЕТ ПРОЕКТ",
  "priorities": "ПЕРВОЕ ВАЖНОЕ\nВТОРОЕ ВАЖНОЕ"
}
JSON
```

Если команда сообщила, что не найден Python или нет `sh`, остановись и скажи владельцу об этом простыми
словами: подключение не выполнено, нужно поставить Python 3.12 или новее (на Windows ещё и Git for Windows),
затем повторить. Потом предложи запустить `/parch:doctor`.

## Шаг 3. Расскажи, что получилось

Ответь владельцу коротко, по-русски:

- что создано (документы в `docs/`, CONSTITUTION, CI, правила защиты) и что пропущено, потому что уже было;
- замечания из отчёта команды (например, что CI для выбранного языка появится позже);
- что нужно сделать дальше: посмотреть `docs/CONSTITUTION.md`, при желании поправить, закоммитить файлы
  и один раз запустить `/parch:doctor`, чтобы убедиться, что защита работает на этом компьютере.

Не правь `docs/CONSTITUTION.md` после создания: это файл владельца, защита потребует его подтверждения.
