## Специфика Claude Code

- Перед работой с plugins, hooks, skills и settings читай актуальную документацию на code.claude.com/docs, а не полагайся на память.
- Плагин проверяется командами `claude plugin validate ./plugin` и `claude plugin validate .`; после правки файлов плагина в живой сессии нужен `/reload-plugins`.
- Если план неясен или противоречит документации, сначала спроси владельца.
