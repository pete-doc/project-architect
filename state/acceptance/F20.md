# Приёмка F20. Сквозной прогон на новом проекте

Проект прогона: новый приватный репозиторий Python на GitHub (адрес вписывается при старте). Блок принимает только
владелец: когда все критерии отмечены и ниже стоит строка «Итог: принято владельцем, ДАТА», блок становится «готово»
на табло. Приёмка F20 закрывает G1 только для Python; остальные языки идут блоками F21–F23. Пока строки нет, блок
ждёт вас. Спецификация: `docs/specs/F20-end-to-end.md`.

## Критерии

Отмечает только владелец: `[x]` — да, `[ ]` — нет или ещё не проверено; рядом с отметкой дата.

- [ ] Подключение: `/parch:init-project` прошёл на новом приватном репозитории одной командой, отчёт понятен без чтения кода (дата: )
- [ ] Цель нового проекта утверждена владельцем: в `docs/GOAL.md` нового проекта нет слова «черновик» в строке статуса (дата: )
- [ ] Репозиторий приватный: на его странице значок «Private» (дата: )
- [ ] CI на GitHub: проверки зелёные в Actions на Ubuntu, прогонов не больше заранее названного числа (дата: )
- [ ] Новая функция через `implementer`: в PR есть «Основания» и тест, CI зелёный (дата: )
- [ ] Заведомое нарушение поймано: CI красный с понятной причиной, слить нельзя (дата: )
- [ ] Ревью и табло: `/parch:review` оставило комментарий в PR, после слияния `state/STATUS.md` на ветке `status` показывает результат (дата: )
