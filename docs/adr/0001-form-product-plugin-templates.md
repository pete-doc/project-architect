# ADR-0001. Форма продукта: плагин + шаблоны

- Статус: proposed
- Тип решения: необратимое (меняет всё, что строится поверх, и то, как продукт ставят пользователи)
- Дата: 2026-10-02

## Контекст

ProjectArchitect должен подключаться к любому проекту и следить за ИИ-разработкой. Нужны две вещи:
код, который работает внутри Claude Code (роли агентов, hooks, команды), и файлы, которые попадают в целевой проект
(CI, документы, состояние).

## Решение

Один репозиторий, две части:

1. `plugin/` — плагин Claude Code. Манифест — `plugin/.claude-plugin/plugin.json`, компоненты (`agents/`, `hooks/`, `skills/`) лежат в корне плагина, а не внутри `.claude-plugin/`, как требует документация.
2. `templates/` — шаблоны документов, CI и состояния. Плагин копирует их в целевой проект командой `/init-project`.

Плагин ставится через каталог `.claude-plugin/marketplace.json` в корне репозитория (источник `./plugin`):
`/plugin marketplace add pete-doc/project-architect`, затем `/plugin install pa@project-architect`.

## Расхождения с BUILD_PLAN.md (решено с владельцем 2026-10-02)

- В план добавлен файл `.claude-plugin/marketplace.json`: без него плагин нельзя установить, `--plugin-dir` работает только на одну сессию.
- Команды плагина всегда имеют префикс его имени. Плагин назван коротко, `pa`, поэтому вместо `/init-project` будет `/pa:init-project`, аналогично `/pa:adr`, `/pa:status`, `/pa:analyze-existing`. Агенты получают префикс так же (`pa:architect` и т. д.).

## Последствия для владельца

- Что изменится: проект получает одну установку плагина и набор файлов-шаблонов, больше ничего ставить не нужно.
- Если решение окажется ошибкой: имя плагина и структуру папок придётся менять, а в уже подключённых проектах нужно будет переустановить плагин и поправить ссылки на команды. Пока подключённых проектов нет, цена отката минимальна. После пилота она резко вырастет.
- Как откатить: удалить плагин (`claude plugin uninstall pa@project-architect`), файлы шаблонов в проектах останутся как обычные файлы и ничего не сломают.

## Рассмотренные альтернативы

- Только `.claude/` внутри каждого проекта: нет версий и обновлений, всё копируется вручную.
- Длинное имя `project-architect`: команды получились бы громоздкими (`/project-architect:init-project`).
