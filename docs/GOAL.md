# GOAL — цель продукта «ProjectArchitect»

> **Статус: утверждена владельцем, 2026-10-03.** Цель продукта меняет и утверждает только владелец
> (STANDARD.md, 6.5). Критерии G1, G2… связаны с блоками работы (`state/features.json`, поле `goal`),
> поэтому их номера не меняют.

## Что это

Набор инструментов (плагин Claude Code и шаблоны), который подключается к программному проекту и держит ИИ-разработку под контролем.

## Для кого

Владелец, который не читает код и ведёт проекты с помощью ИИ на Python, TypeScript, C# и PowerShell.

## Критерии готовности продукта

Каждый критерий проверяемый: по нему можно сказать «выполнено» или «нет».

- **G1.** Проект на любом из четырёх языков подключается одной командой, и результат проверен на живом проекте
- **G2.** ИИ не может «заглушить» проверки: удалённые и пропущенные тесты, дубли, мёртвый код и нарушения границ ловятся на всех четырёх языках
- **G3.** Владелец видит состояние проекта на одной странице и не читает код
- **G4.** Существующий проект можно проверить и привести к стандарту
- **G5.** CI не тратит квоту впустую
- **G6.** ИИ не теряет нить проекта: петли обнаруживаются, решения и уроки не забываются, цель прослеживается до кода

## Что в продукт НЕ входит

- Работа ИИ-агентов вне Claude Code и Cursor
- Внешние трекеры задач (Jira и подобные)
